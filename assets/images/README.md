# Optional image assets

Lunar Ride runs without these files; it falls back to procedural textures/skies and hides missing artwork.
For the exact original look, copy these files into this folder:

- `bike rider.jfif`
- `space stations moon.jfif`
- `space stations mars.jfif`
- `sky_kepler.jpg`
- `tex_grass.jpg`
- `tex_rock.jpg`
- `tex_asphalt.jpg`
