# Aqua Rift fish assets — provenance

These models are by **Quaternius**, released as **CC0 / Public Domain**, and were sourced in GLB form from the public `Mnehmos/exhibit-of-shadows` repository at pinned commit `e160070ede35d2d1a62c7572e8b348211c58fe83`. That repository records the Poly Pizza model pages below. The GLBs are converted here losslessly to glTF 2.0 JSON with the binary buffer embedded as a data URI so Lunar Ride's existing glTF loader can consume them.
